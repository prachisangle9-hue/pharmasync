# 💊 Pharmacy Management System

A modern Java-based Pharmacy Management System designed to simplify pharmacy operations with smart inventory management, secure billing, analytics, and role-based access.

---

## 📖 Project Overview

The Pharmacy Management System is a desktop application developed using Java and MySQL. It helps pharmacies manage medicines, billing, inventory, customers, and sales efficiently. The project includes modern features like barcode support, QR code billing, AI-based medicine suggestions, and sales analytics.
